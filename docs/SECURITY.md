# 安全与上线清单
- 用户级登录尝试限制、注册尝试限制、举报次数限制。现有可信代理 IP 级限流代码默认关闭，必须完成源站隔离、代理头覆盖和真实预发布联调后才能启用；邮件验证、密码找回、会话清理与敏感日志脱敏仍待完成。
- 付费全文只在服务器验证已支付权限后选择查询；缓存禁用。后台页面和 Server Actions 分别检查管理员身份。
- 招聘真实性、来源授权、过期与投诉处理；2025-12-25 人社厅发〔2025〕60号要求依法取得相应网络招聘服务资质。正式运营前须咨询当地人社部门、核实收费合法性并完善经营主体、客服、隐私政策及退款条款。
- 真实支付默认禁用；商户查单、关闭、退款、对账、资金异常处理及真实测试尚未完成。
- 过期 Session/AuthAttempt 已有独立的默认只读 `auth:retention` 维护命令（`--apply` 需显式审批开关），尚未通过实际删除测试或设定生产周期调度。见 `docs/goal/mvp/auth-retention-2026-11-18.md`。
- AI 模型出站接口新增精确批准列表 `AI_APPROVED_BASE_URLS` 和有界流式读取；仍需真实预发布 DNS/出口 ACL、隐私协议、成本与模型质量验收。见 `docs/goal/mvp/ai-provider-egress-2026-11-18.md`。
- `/api/readyz` 数据库就绪接口在无凭据时默认 404；部署前需要强随机凭据、内部网络 ACL 和探针请求限流。见 `docs/goal/mvp/readiness-probe-2026-11-18.md`。
- 支付回调和商户查单已改为按原始字节流式限额读取，避免先完整下载再检查；仍须代理/CDN 端请求上限、压测及完整回归，见 `docs/goal/mvp/payment-body-bounds-2026-11-18.md`。
- 支付回调 `APP_ORIGIN` 启用检查和回调 URL 生成使用同一公共 HTTPS 源校验，避免 HTTPS 协议检查过宽；仍须核定 DNS、TLS、回调可达性和商户侧设置，见 `docs/goal/mvp/payment-origin-gate-2026-11-18.md`。
- 不得提交生产用户数据及商户证书。
