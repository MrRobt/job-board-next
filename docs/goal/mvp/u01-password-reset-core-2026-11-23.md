- 继续上一 U01 已验收邮箱验证工作，不重复改变注册/登录。新增 `PasswordResetToken` 专有存储（SHA-256 摘要 PK、每用户唯一、过期时间、级联删除），与邮箱验证凭据用途隔离；Prisma 版本化迁移 `20261123000200_password_reset_token` 为纯新表，不修改任何已有密码或账号状态。

- 新增无外发的规则测试 `tests/password-reset-policy.test.ts`，以及隔离 MySQL8 `tests/integration/password-reset.test.ts`（仅合成用户/旧会话，验证未验证账号拒绝、轮换、过期/坏密码拒绝、并发仅一例成功、旧密码失效/新密码有效、会话撤销、重放拒绝）。
