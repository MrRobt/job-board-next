4. 文件长度 **22,573 bytes**；SHA-256：`cd9dfc159014a1b25a9bb02d59a17ab8b2bdf2018424cabf623e809af07cc550`。
5. 在同一专用容器新建完全不同名称的空库 `jobs_mvp_restore_20261118_61ac`，使用 MySQL 客户端 `SOURCE` 导入备份，exit 0；没有 DROP/覆盖源库或其他库。
