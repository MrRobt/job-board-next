# B07 · 数据库恢复就绪只读预检（2026-11-21）

## 工作包与安全范围

在职讯集授权工作区 `F:\code\job-board-next`，新增 `scripts/b07-recovery-preflight.mjs` 与 `tests/b07-recovery-preflight.test.ts`。这是**只读恢复前检查**，不是数据库备份或恢复，也不证明业务可以上线。

原计划编写一次性备份/恢复执行程序，但涉及高权限数据库凭据传递的脚本写入被工作区安全策略拒绝。**没有绕过限制、没有生成该脚本、没有创建/删除/覆盖数据库**。转而实施严格限定隔离数据库的只读预检。任何真实备份、导入、恢复和凭据操作必须在授权运维环境由有权人员执行。

## 只读检测内容

1. 缺少 `DJS_RECOVERY_PREFLIGHT_APPROVED=READ_ONLY` 或 `INTEGRATION_TEST_DATABASE=true` 一律拒绝，`NODE_ENV=production` 一律拒绝。
2. 数据库地址必须是本机 `127.0.0.1/localhost:3306`，库名限定 `jobs_mvp_migrate_YYYYMMDD_*`；不检查、不连接正常业务 `jobs`、远程/其它端口/其它项目库。
3. 只执行 MySQL SELECT：读取 `information_schema` 的关键表/列、`_prisma_migrations` 已完成/失败记录、财务异常记录**聚合计数**。本地 8 个迁移文件计算 SHA-256 校验和，并与数据库登记值比较。
4. 输出不包含邮箱、密码、商户交易号、请求令牌、业务正文及数据库连接信息中的凭据。
5. 检测待执行/未完成/未知/校验和不一致迁移，缺少关键财务列或金额字段类型异常时以非零退出。不执行任何 schema 更新、备份、DROP 或 SQL 导入。
