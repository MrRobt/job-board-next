# A01 · 本页逐轮模拟面试（2026-11-21）

## 范围与实现

基于长期 Goal 已有的 `questions` 和 `feedback` 两种练习请求类型，完成一个可操作的本地逐轮工作流，而非重新建设 AI Provider、支付或次数账本。

- `components/CareerForm.tsx`：在面试工具中展示逐轮练习进度。从已生成的题目列表点击某道题，自动切换到回答反馈模式、将题目放入当前问题字段、保留目标岗位。查看反馈后可重新选题继续下一轮。
- 当前页面最多 **5 轮**。在 React 内存中只保留各轮问题、反馈摘要及“规则示例/AI”来源，不保存完整回答；可手动清空，刷新/关闭后自然清空。目标岗位改变时旧轮次清空，避免混合不同岗位的练习。
- `lib/career/interview-rounds.ts`：纯状态辅助函数，对题目/摘要长度、练习方式和轮次上限进行校验，返回新数组，不修改旧状态。
- 规则样例与 AI 分别标明，选择题目不会自动调用 AI；原有每次 AI 请求必须经用户同意、按原业务独立计次，失败返还机制不变。
- 未添加数据库模型、session cookie、外部连接器、本地持久存储或绕过服务端输入及隐私校验。用户若需要保留报告，仍需自行复制。
