# A02 模型报告外链安全门禁 · 2026-11-21

## 背景与本包交付

既有 `lib/career/output-safety.ts` 仅检查手机号、邮箱、证件号，可能将模型编造的外部收集页、下载地址、邮件/电话跳转作为“求职建议”交付用户。本轮扩展最终的模型报告输出校验，不改变模型输入、提供商配置、用户次数结算、数据库或商户资金。

- 在输出 Schema 校验、个人联系方式检查之后，逐个检查报告 `summary`、全部 `sections[].title/items`、全部 `next[]` 文本。
- 拒绝 `https://`、`http://`、`ftp://`、`www.`、`mailto:`、`tel:`、`sms:` 和常见后缀的裸域名等外部目的地。对 Unicode NFKC 与零宽字符做检测用规范化，抵御部分常见 URL 混淆。
- 拒绝时仅报告固定错误 `Model output contains an external link`，不回显模型编造的 URL/内容，也不在最终报告中交付可疑链接。
- 裸域名匹配仅限常见域名后缀，避免误杀求职技术材料里的 `Node.js`、`Python.py`、版本号。此安全过滤不是通用 URL 解析器、DNS 校验或完整反钓鱼产品，未知/新型后缀与复杂混淆仍需后续审计。
