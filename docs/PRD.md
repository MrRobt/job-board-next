# 职讯集 MVP
- 访客浏览已发布、未过期岗位，支持行业、关键词筛选，详情展示摘要。
- 免费岗位直接查看全文和申请来源；付费岗位仅登录并购买后服务端返回全文。
- 后台仅管理员访问：招聘新增、编辑、发布、下架，分类维护，订单查询。
- 用户邮箱密码注册/登录，查看已购信息及订单。
- 人民币整数分计价；支付宝、微信商户支付；回调验签、订单金额核对、幂等、唯一解锁，退款后撤销权限。
- 第一阶段仅内部模拟支付用于测试；真实支付未实现前生产环境禁用购买。
- 上线前：确认经营资质、信息来源授权、求职者收费合法性；不发布虚假招聘，不承诺录用，提供举报和退款入口。
- 不做企业入驻、聊天、简历、推荐算法。
