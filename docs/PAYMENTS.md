# 商户支付（开发中，禁止正式收款）
支付宝普通公钥模式电脑网站支付（RSA2）；微信支付 API v3 直连商户 Native、公钥模式（非平台证书）。仅服务端异步通知经签名、商户、交易号及整数分金额校验后发放访问权限。微信通知先验签后 AES-GCM 解密。订单 activeKey 唯一约束避免切换渠道重复创建待支付订单。
默认 ENABLE_REAL_PAYMENT=false。不要在 GitHub 存储证书或私钥。APP_ORIGIN 必须是公开 HTTPS origin。密钥以环境变量配置。
已开发管理员发起的签名查单与安全关单（ENABLE_PAYMENT_RECONCILIATION 默认关闭），离线模拟测试通过；尚未完成真实商户联调、退款和自动对账，待支付订单无法切换支付渠道；人工对账前不得手工改状态。订单页面只显示数据库真实回调结果。支付宝页面支付适用于 PC；移动端 H5/JSAPI 后续实现。
